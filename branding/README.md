# Pygg branding

**Product:** Pygg  
**Engineering repository:** SmartTaskRouter  
**Tagline:** One Flow. Many Agents.

## Brand assets

- `pygg-logo.svg` — horizontal mark, wordmark and slogan on white, for README and landing pages.
- `pygg-icon.svg` — square symbol for app and web surfaces.
- `brand.json` — name, tagline, colors and paths.

The two green accent nodes use **`#0B7A4B`**, the app's light-theme `--accent` in `apps/desktop/src/styles.css`. Dark UI uses `#0D8551`. SVGs are scalable and can be exported to PNG sizes as needed.

The existing `apps/desktop/src/assets/brand-mark.svg` and Tauri app icons have not been replaced: changing runtime branding requires separate UI and packaging checks.
